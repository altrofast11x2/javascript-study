앞의 결과가 있어야 다음을 할 파고듭니다. 이걸 콜백지옥이라고 불렀어요. 게다가 에러 처리를 단계마다 따로 해줘야 합니다. 이걸 해결하려고 나온 게 Promise입니다.


Promise가 그 진동벨입니다. 함수가 결과 대신 "나중에 결과를 줄게"라는 약속을 즉시 돌려줘요.

const wait1 = () => new Promise(resolve => {
  setTimeout(() => resolve("완료!"), 1000)
  //             ↑ resolve 를 부르는 순간이 "진동벨이 울리는" 순간
})

console.log(wait1())   // Promise {<pending>}  ← 커피가 아니라 진동벨

상태가 셋입니다.

┌───────────┬────────────────┬───────────────────┐
│   상태    │       뜻       │       카페        │
├───────────┼───────────────
│ pending   │ 아직 진행 중   │ 커피 만드는 중    │
├───────────┼────────────────┼───────────────────┤
│ fulfilled │ 성공 (resolve)
├───────────┼────────────────┼───────────────────┤
│ rejected  │ 실패 (reject)  │ 재료가 떨어졌대요 │
└───────────┴───────────────

결과를 꺼내려면 .then을 씁니다.

wait1()
  .then(값 => console.log(값))      // 성공하면
  .catch(err => console.log(err))   // 실패하면
