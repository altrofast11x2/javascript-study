# 09 - canvas
1. canvas는 왜 필요한가

지금까지 화면에 뭘 띄우는 방법은 태그를 만들어 붙이는 것 하나였습니다.

list.append(nl("div", { textContent: "책" }))

근데 이걸로 못 하는 게 있어요.

· 선 하나 긋기            <div> 로 1px 선? 가능하긴 한데 대각선은?
· 원, 삼각형, 곡선         border-radius 로 원은 되는데 삼각형은 꼼수
· 점 1000개 찍기          <div> 1000개 = 브라우저 사망
· 게임, 차트, 그림판        말할 것도 없음

**DOM은 "상자를 배치하는 도구"**지 그림 도구가 아닙니다. 그래서 브라우저가 그림판을 따로 줍니다. 그게 <canvas>예요.

2. canvas는 요소가 아니라 "그림판"입니다 ⭐⭐

이게 제일 중요한 차이입니다.

// DOM — 그린 것이 "요소"로 남는다
const d = nl("div", { textContent: "책" })
list.append(d)
d.textContent = "다른 책"        // 나중에 찾아서 고칠 수 있음

// canvas — 그린 것은 "픽셀"로만 남는다
ctx.fillRect(10, 10, 50, 50)     // 사각형을 그림
// ...이 사각형을 나중에 어떻게 찾죠?  못 찾습니다

canvas에 그린 건 물감입니다. 도화지에 칠해진 색일 뿐, "사각형 객체" 같은 건 없어요. 그래서:

┌─────────────┬────────────────────────┬────────────────────┐
│             │          DOM           │       canvas       │
├─────────────┼────────────────────────┼────────────────────┤
│ 그린 것     │ 요소로 남음            │ 픽셀로만 남음      │
├─────────────┼────────────────────────┼────────────────────┤
│ 나중에 수정 │ querySelector로 찾아서 │ 못 찾음            │
├─────────────┼────────────────────────┼────────────────────┤
│ 클릭 이벤트 │ 요소마다 붙임          │ canvas 전체에 하나 │
├─────────────┼────────────────────────┼────────────────────┤
│ 움직이려면  │ style.left 바꾸기      │ 지우고 다시 그리기 │
└─────────────┴────────────────────────┴────────────────────┘

"움직이려면 지우고 다시 그린다" — 이게 Day 10 애니메이션의 전부입니다. 미리 기억해두세요.

3. 시작하는 법

<canvas id="cv" width="400" height="300"></canvas>
const cv = $("#cv")
const ctx = cv.getContext("2d")     // ← 붓을 꺼낸다

ctx가 붓입니다. 앞으로 모든 그리기는 ctx. 으로 시작해요. cv는 도화지고, ctx는 그 위에 칠하는 도구입니다.

▎ "2d" 말고 "webgl" 도 있는데 3D용이라 우리랑 상관없습니다.

4. 크기 함정 — 여기서 제일 많이 당합니다 ⭐⭐⭐

<canvas id="cv" width="400" height="300"></canvas>   <!-- ① 속성 -->
#cv { width: 400px; height: 300px; }                 /* ② CSS */

이 둘은 완전히 다릅니다.

① width 속성   도화지의 "실제 픽셀 수"      -> 400칸짜리 모눈종이
② CSS width    화면에 "보이는 크기"         -> 그 종이를 몇 cm 로 늘려 보여줄지

CSS로만 크기를 주면 작은 그림을 늘려서 보여주는 것이라 흐릿해지고 좌표도 어긋납니다.

/* ❌ 이렇게 하면 */
#cv { width: 800px; height: 600px; }
/* 기본 300×150 도화지를 800×600 으로 잡아늘림 -> 뭉개짐 */

규칙: 크기는 HTML 속성으로 주세요. CSS는 테두리나 배경에만 쓰고요.

▎ 또 하나 — cv.width = 500 처럼 JS로 크기를 바꾸면 도화지가 통째로 지워집니다. 지우는 용도로 쓰는 사람도 있는데, 보통은 사고예요.

5. 좌표계 — y가 아래로 갑니다

(0,0) ┌──────────────→ x
      │
      │     · (50, 30)
      │
      ↓
      y

왼쪽 위가 (0,0), y는 아래로 증가합니다. 수학 시간의 그래프와 위아래가 뒤집혀 있어요. 원점이 왼쪽 아래가 아니라 위입니다.

6. 사각형 — 유일하게 한 줄로 되는 도형

ctx.fillRect(x, y, 너비, 높이)      // 채운 사각형
ctx.strokeRect(x, y, 너비, 높이)    // 테두리만
ctx.clearRect(x, y, 너비, 높이)     // 그 영역을 지움 (투명하게)

ctx.fillRect(10, 10, 100, 50)       // (10,10) 에서 가로 100, 세로 50

x, y는 왼쪽 위 모서리입니다. 중심이 아니에요.

clearRect는 전체 지우기에 씁니다. 애니메이션의 첫 줄이 거의 항상 이겁니다.

ctx.clearRect(0, 0, cv.width, cv.height)   // 도화지 전체 지우기

7. 색은 "그리기 전에" 정합니다 ⭐⭐

ctx.fillStyle = "tomato"       // 채우기 색
ctx.strokeStyle = "gold"       // 선 색
ctx.lineWidth = 4              // 선 두께

ctx.fillRect(10, 10, 50, 50)   // 이제 그림

순서가 반대면 안 먹습니다.

// ❌ 그리고 나서 색을 정함
ctx.fillRect(10, 10, 50, 50)
ctx.fillStyle = "tomato"        // 이미 그려진 건 안 바뀜 (픽셀이니까!)

// ✅ 색 먼저
ctx.fillStyle = "tomato"
ctx.fillRect(10, 10, 50, 50)

2번 항목이 여기서 체감됩니다. 이미 칠한 물감은 못 바꿔요.

그리고 fillStyle은 한 번 정하면 계속 유지됩니다. 다음 도형도 같은 색으로 그려져요. 바꾸고 싶으면 다시 지정해야 합니다.

8. 경로 — 사각형 말고 다른 건 다 이걸로 ⭐⭐⭐

선, 삼각형, 다각형은 "연필을 움직여 길을 만들고 → 그 길을 그린다" 입니다.

ctx.beginPath()             // ① 새 길 시작
ctx.moveTo(50, 50)          // ② 연필 들고 여기로 이동
ctx.lineTo(150, 50)         // ③ 여기까지 선
ctx.lineTo(100, 130)        // ④ 여기까지 선
ctx.closePath()             // ⑤ 시작점까지 자동으로 닫기
ctx.stroke()                // ⑥ 그 길을 선으로 그린다

┌──────────────┬─────────────────────────────────┐
│              │             하는 일             │
├──────────────┼─────────────────────────────────┤
│ beginPath()  │ 새 길 시작 (이전 길을 버림)     │
├──────────────┼─────────────────────────────────┤
│ moveTo(x, y) │ 연필을 들고 이동 (선 안 그림)   │
├──────────────┼─────────────────────────────────┤
│ lineTo(x, y) │ 연필을 대고 이동 (선 그림)      │
├──────────────┼─────────────────────────────────┤
│ closePath()  │ 시작점으로 선 하나 더 그어 닫기 │
├──────────────┼─────────────────────────────────┤
│ stroke()     │ 길을 선으로 그림                │
├──────────────┼─────────────────────────────────┤
│ fill()       │ 길 안쪽을 채움                  │
└──────────────┴─────────────────────────────────┘

moveTo와 lineTo는 아직 아무것도 안 그립니다. 설계만 하는 거예요. stroke() 나 fill() 을 불러야 그때 그려집니다.

beginPath() 안 부르면 생기는 일 ⭐

// ❌
ctx.moveTo(10, 10); ctx.lineTo(100, 10); ctx.stroke()
ctx.moveTo(10, 50); ctx.lineTo(100, 50); ctx.stroke()

둘째 stroke() 에서 첫 번째 선까지 다시 그립니다. 길이 안 지워졌거든요. 색을 바꿨다면 첫 선 색까지 바뀝니다.

▎ 새 도형을 그릴 때마다 beginPath(). 이거 안 해서 생기는 버그가 canvas 1위입니다.

9. 원 — arc는 라디안을 씁니다 ⚠️

ctx.beginPath()
ctx.arc(x, y, 반지름, 시작각, 끝각)
ctx.fill()

ctx.arc(100, 100, 40, 0, Math.PI * 2)     // 완전한 원

각도가 도(°)가 아니라 라디안입니다.

Math.PI * 2   =  360°   (한 바퀴)
Math.PI       =  180°   (반 바퀴)
Math.PI / 2   =   90°

도를 쓰고 싶으면 바꿔야 합니다.

const rad = (도) => 도 * Math.PI / 180
ctx.arc(100, 100, 40, 0, rad(360))

▎ arc의 x, y는 중심입니다. 사각형은 왼쪽 위였는데 원은 중심이에요. 헷갈리기 쉬운 지점입니다.

10. 글자

ctx.font = "20px sans-serif"     // 크기와 글꼴을 한 문자열로
ctx.fillStyle = "white"
ctx.textAlign = "center"         // left(기본) / center / right
ctx.textBaseline = "middle"      // 세로 기준
ctx.fillText("안녕", 100, 50)

font는 CSS의 font 속성과 같은 문법입니다. 크기만 쓰면 안 되고 글꼴까지 적어야 해요 — "20px" 만 쓰면 무시됩니다.

ctx.measureText("안녕").width    // 글자 폭 재기 (가운데 정렬 계산용)

11. 이미지 — 여기서 Day 08이 돌아옵니다 ⭐⭐

const img = new Image()
img.src = "cat.png"
ctx.drawImage(img, 0, 0)      // ❌ 아무것도 안 그려집니다

이미지는 즉시 로드되지 않습니다. src를 넣는 건 "받아와" 라고 시키는 것뿐이고, 아직 안 왔어요. 비동기입니다.

const img = new Image()
img.onload = () => ctx.drawImage(img, 0, 0)    // ✅ 다 받으면 그린다
img.src = "cat.png"                             // 시키는 건 나중 줄

onload를 먼저 걸고 src를 나중에 거는 게 관례입니다. (캐시에 있으면 src 넣는 순간 즉시 로드돼서 onload를 놓칠 수 있어요)

drawImage는 인자 개수에 따라 다르게 동작합니다.

ctx.drawImage(img, x, y)                  // 원본 크기로
ctx.drawImage(img, x, y, w, h)            // 크기 지정
ctx.drawImage(img, sx,sy,sw,sh, x,y,w,h)  // 원본 일부만 잘라서 (스프라이트)

12. 상태 저장 — save / restore

fillStyle, lineWidth 같은 설정은 계속 유지된다고 했죠. 잠깐만 바꾸고 되돌리고 싶을 때 씁니다.

ctx.save()                    // 지금 설정을 저장
ctx.fillStyle = "red"
ctx.fillRect(0, 0, 50, 50)
ctx.restore()                 // 저장해둔 설정으로 복귀

이동·회전과 같이 쓸 때 진가가 나옵니다.

ctx.save()
ctx.translate(100, 100)       // 원점을 (100,100) 으로 옮김
ctx.rotate(Math.PI / 4)       // 45도 회전
ctx.fillRect(-25, -25, 50, 50) // 원점 기준으로 그림 -> 중심 회전
ctx.restore()                 // 원점·회전 원래대로

rotate는 도형이 아니라 "좌표계"를 돌립니다. 그래서 translate로 중심을 먼저 옮기고, 도형을 -절반 위치에 그려야 제자리에서 돕니다. Day 10에서 많이 씁니다.
