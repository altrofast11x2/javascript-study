1. 배열의 기본

const fruits = ['사과','바나나','포도']
fruits[0] //"사과" 0부터 읽기때문
fruits[2] //"포도"
fruits[99] //undefined <- 에러 안남 array 가 존재하나 안에 값은 없기 때문
fruits.length // 3
fruits[fruits.length - 1] //"포도" (마지막(즉 반대로 읽을수도 있을 이렇게))

const인데 값을 바꿀수 있긴함.

const fruits = ["사과"]

fruits = ["딸기"] //"에러"

2. 추가 / 삭제
const arr = [1,2,3]
arr.push(4) //뒤에 추가 [1,2,3,4]
arr.pop() //뒤에서 빼기 [1,2,3]
arr.unshift(0) //앞에서 추가 [0,1,2,3]
arr.shift() //앞에서 빼기 [1,2,3]

push가 압도적으로 많이 쓰이고. PHP의 $arr[] = 4와 같습니다

3. map() - 전부 바꾸기 

배열의 모든 원소를 가공해서 같은 길이의 새배열을 만듬.
const nums = [1,2,3]
const dobuled = nums.map(n=>n * 2) 
console.log(doubled) // [2,4,6]
console.log(nums) // [1,2,3] 원본 그대로 출력한거기 때문

forEach 와 핵심 차이 ㄱ
┌─────────┬────────────────────────────────┐
│         │             반환값             │
├─────────┼────────────────────────────────┤
│ forEach │ 없음 (undefined) — 그냥 훑기만 │
├─────────┼────────────────────────────────┤
│ map     │ 새 배열 — 받아서 또 씀         │
└─────────┴────────────────────────────────┘

쓰임 기준 ㄱ

┌─────────────────────────────────┬─────────┐
│            하려는 일            │  쓸 것  │
├─────────────────────────────────┼─────────┤
│ 화면에 찍기만 / DOM에 붙이기만  │ forEach │
├─────────────────────────────────┼─────────┤
│ 가공한 결과를 받아서 또 써야 함 │ map     │
└─────────────────────────────────┴─────────┘

cosnt r1 = nums.foreach(n => n *2) //undefined <- 
cosnt r2 = nums.map(n => n *2) //[2,4,6]
!중요 .map() 콜백에서 return을 빼먹으면 전부 undefined가 됩니다. 화살표 축약형(n => n * 2)을 쓰면 자동 return이라 안전함

4. filter() - 걸러내기
조건이 참인 것만 골라서 새 배열을 만듬.

const nums = [1,2,3,4,5,6]
const even = nums.filter(n=> n % 2 === 0) //[2,4,6]
const big = nums.filter(n=> n > 3) //[4,5,6]

콜백이 true/false를 돌려주면 됨.

map 과 filter를 이어붙일수도 있음. 우리는 이걸 ★체이닝★ 이라고함.
const scores = [95,88,72,100,61] 
const result = scores
    .filter(s=> s >= 90)  // [95, 88, 100]
    .map(s=> `${s}점 합격`) // ["95점 합격", "88점 합격", "100점 합격"]

    filter가 새 배열을 반환하니까 바로 거기다가 map을 붙일수 있는거임.

5. find()

const nums = [1,5,12,8]
nums.find(n => n > 4) // 5첫 번째 것 하나만. 배열이 아님.
nums.filter(n=> n > 4) // [5,12,8] 전부 배열
nums.find(n=> n > 100) //undefined

!주의 filter 는 배열 find() 는 원소 하나임.

8. sort() - 함정 있음

const nums = [10,9,100,1]
nums.sort()
console.log(nums) //[1,10,100,9] <- ??? 

sort()는 기본적으로 문자열로 바꿔서 정렬합니다, 그래서 "9" 거 "100" 보다 뒤로 감. 숫자를 정렬하려면 비교함수를 넘겨야합니다.

nums.sort((a,b) => a - b) //[1,9,10,100] -> 오름차순
nums.sort((a,b) => b - a) //[100,10,9,1] -> 내림차순

★ 외우기!! -> a - b 면은 작은거 부터.

11. 원본을 바꾸느냐, 새로 만드느냐

이게 배열 메서드를 가르는 가장 중요한 기준입니다.

┌────────────────────────┬───────────────────────────┐
│      원본을 바꿈       │ 원본 그대로, 새 배열 반환 │
├────────────────────────┼───────────────────────────┤
│ push pop shift unshift │ map filter slice concat   │
├────────────────────────┼───────────────────────────┤
│ sort reverse splice    │ join (문자열 반환)        │
└────────────────────────┴───────────────────────────┘

const a = [3,1,2]
const b = a.sort() // a도 같이 바뀜! b와 a는 같은 배열
const c = [3,1,2].map(n=>n) //새로운 배열

sort가 원본을 바꾸는건 실무에서 진짜 자주 사고남. 원본을 지키려면 복사부터 하고 하는걸 권장함.

const soted = [...nums].sort((a,b)=> a - b) //원본 안전함.
[...nums]는 스프레드라고 하는데, 배열을 펼쳐서 새 배열에 담는 문법입니다. 지금은 복사 하는방법 정도로만 알면됨.
