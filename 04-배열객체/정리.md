3. map() - 전부 바꾸기 

배열의 모든 원소를 가공해서 같은 길이의 새배열을 만듬.
const nums = [1,2,3]
const doubled = nums.map(n=>n * 2) 
console.log(doubled) // [2,4,6]
console.log(nums) // [1,2,3] 원본 그대로 출력한거기 때문

forEach 와 핵심 차이 ㄱ
┌─────────┬────────────────────────────────┐
│         │             반환값             │
├─────────┼────────────────────────────────┤
│ forEach │ 없음 (undefined) — 그냥 훑기만 │
├─────────┼────────────────────────────────┤
│ map     │ 새 배열 — 받아서 또 씀         │
└─────────┴────────────────────────────────┘

쓰임 기준 ㄱ

┌─────────────────────────────────┬─────────┐
│            하려는 일            │  쓸 것  │
├─────────────────────────────────┼─────────┤
│ 화면에 찍기만 / DOM에 붙이기만  │ forEach │
├─────────────────────────────────┼─────────┤
│ 가공한 결과를 받아서 또 써야 함 │ map     │
└─────────────────────────────────┴─────────┘

const r1 = nums.forEach(n => n *2) //undefined <- 
const r2 = nums.map(n => n *2) //[2,4,6]
!중요 .map() 콜백에서 return을 빼먹으면 전부 undefined가 됩니다. 화살표 축약형(n => n * 2)을 쓰면 자동 return이라 안전함

4. filter() - 걸러내기
조건이 참인 것만 골라서 새 배열을 만듬.

const nums = [1,2,3,4,5,6]
const even = nums.filter(n=> n % 2 === 0) //[2,4,6]
const big = nums.filter(n=> n > 3) //[4,5,6]

콜백이 true/false를 돌려주면 됨.

map 과 filter를 이어붙일수도 있음. 우리는 이걸 ★체이닝★ 이라고함.
const scores = [95,88,72,100,61] 
const result = scores
    .filter(s=> s >= 90)  // [95,100]
    .map(s=> `${s}점 합격`) // ["95점 합격", "100점 합격"]

    filter가 새 배열을 반환하니까 바로 거기다가 map을 붙일수 있는거임.

8. sort() - 함정 있음

const nums = [10,9,100,1]
nums.sort()
console.log(nums) //[1,10,100,9] <- ??? 

sort()는 기본적으로 문자열로 바꿔서 정렬합니다, 그래서 "9"가 "100"보다 뒤로 감. 숫자를 정렬하려면 비교함수를 넘겨야합니다.

nums.sort((a,b) => a - b) //[1,9,10,100] -> 오름차순
nums.sort((a,b) => b - a) //[100,10,9,1] -> 내림차순

★ 외우기!! -> a - b 면은 작은거 부터.

11. 원본을 바꾸느냐, 새로 만드느냐

이게 배열 메서드를 가르는 가장 중요한 기준입니다.

┌────────────────────────┬───────────────────────────┐
│      원본을 바꿈       │ 원본 그대로, 새 배열 반환 │
├────────────────────────┼───────────────────────────┤
│ push pop shift unshift │ map filter slice concat   │
├────────────────────────┼───────────────────────────┤
│ sort reverse splice    │ join (문자열 반환)        │
└────────────────────────┴───────────────────────────┘

const a = [3,1,2]
const b = a.sort() // a도 같이 바뀜! b와 a는 같은 배열
const c = [3,1,2].map(n=>n) //새로운 배열

sort가 원본을 바꾸는건 실무에서 진짜 자주 사고남. 원본을 지키려면 복사부터 하고 하는걸 권장함.

const sorted = [...nums].sort((a,b)=> a - b) //원본 안전함.
[...nums]는 스프레드라고 하는데, 배열을 펼쳐서 새 배열에 담는 문법입니다. 지금은 복사 하는방법 정도로만 알면됨.

4. 객체 순회
객체는 for...of 가 안됩니다. (배열이 아니라서)
const user = {name:"노벨",age: 21}
Object.keys(user) // ["name","age"]
Object.values(user) // ["노벨", 21] <- 21은 숫자 그대로
Object.entries(user) // [["name","노벨"],["age", 21]]

셋다 배열을 돌려주니까 배열 메서드를 붙일수 있음.

Object.entries(user).forEach(([k,v])=>{
    console.log(`${k}: ${v}`)
})
// name: 노벨
// age: 21
PHP의 foreach ($user as $k => $v)가 JS 에서 이모양임.

5. 객체 배열 - 실전 데이터는 대부분 이럼.
const user = [
    {name:"노벨",age:21,city:"서울"},
    {name:"용선",age:25,city:"부산"}
]
user[0].name // "노벨" <- 배열로 꺼내고, 객체로 꺼내고
user.length // 2

핵심은 PART1 의 배열의 메서드가 전부 그대로 먹힌다는거임.

user.map(u=>u.name) //["노벨","용선"]
user.filter(u=>u.age > 22) //[{name:"용선",age:25,city:"부산"}] <- 객체가 든 배열
user.find(u=>u.city === "서울") //{name:"노벨",age:21,city:"서울"} <- 배열 아님, 객체 하나

서버에서 오는 데이터, 즉 PHP json_encode가 뱉는 데이터가 전부 이 형태입니다. DOM에서 목록 그릴때 이걸 map으로 돌려서 화면에 뿌립니다.

6. 구조 분해 할당 (Destructuring)

객체에서 값을 꺼내 변수로 바로 빼는 문법입니다.

const user = {name:"노벨",age:21}
const {name, age} = user 

//const name = user.name
//const age = user.age <- 위에 처럼 쓰면 이 두줄과 완전히 같음.

규칙 3개 
const {city} = user //undefined <- 없는키
const {city = "서울"} = user // "서울" <- 기본값
const {name: userName} = user // "노벨" <- 이름 바꿔 받기

변수 이름이 키 이름과 같아야 꺼내집니다. 순서는 상관없고 (배열 구조분해는 순서 기준이라 반대입니다).
