2. 삼항 연산자 (한줄짜리 if / else)
const age = 21
const result = age >= 19 ? "성인" : "미성년자"
삼항 연산자 구조 ㄱ

조건 ? 참일때 값 : 거짓일때 값

3. for 반복문

for(let i =0;i <= 5;i++){
    console.log(i) //0 1 2 3 4 5 
}

i = 0 에서 시작하고 i < 5인 동안 계속 반복함 한바퀴가 끝날때마다 i++
여기서 i 는 let 을 써야함. 계속 i가 바뀌기 떄문에.

4. 배열 순회
PHP의 foreach ($fruits as $fruit)와 같은 거임. 인덱스가 필요 없으면 이게 훨씬 깔끔함.

const friends = ['노벨','유준영','권용선']
for (const friend of friends){
    console.log(friend)
}

5. forEach (배열 메서드)

주의! foreach 아니고 forEach. 가운데 E 대문자.
const fruits = ['사과','바나나','포도']

fruits.forEach(fruit => {
    console.log(fruit)
})

괄호 안에 함수를 통째로 넣는다. 이렇게 남한테 넘겨주는 함수를 콜백(callback) 이라고 함.
forEach 가 배열을 돌면서 원소를 하나씩 꺼내 내 함수에 인자로 넣고 호출해줌.

두번째 매개변수는 인덱스.
fruits.forEach((fruit, i) => {
    console.log(`${i}번: ${fruit}`)  // 0번: 사과 ...
})
PHP의 foreach ($fruits as $i => $fruit) 랑 같음.

*** for...of 와의 결정적 차이 ***
forEach 는 break / continue 를 못 씀! (콜백은 반복문이 아니라 그냥 함수라서)

  중간에 멈춰야 함  -> for...of
  전부 다 훑기만 함 -> forEach
