1. 변수
변수는 let, const 두 개만

let age = 20;         // 값이 바뀔 수 있는 것
const name = "노벨";   // 값이 안 바뀌는 것

age = 21;             // OK
name = "홍길동";       // 에러

명심할것 -> 기본은 무조건 const, 바꿔야 할 때만 let으로 쓰자.

2. 자료형

"문자열"      // string
123          // number  
true         // boolean
[1, 2, 3]    // array
{ a: 1 }     // object

3. 백틱

console.log(`안녕 ${name}, 너는 ${age}살`)
console.log(`내년이면 ${age + 1}살`)

4. 항상 === 를 쓰자 

1 == "1" //true 타입을 멋대로 바꿔서 비교
1 === "1" //false 타입까지 비교
그리고 추가로 개선해야할것 -> <script></script> 는 </body> 밖에 말고 안에 써야함.
